WHILE IN directory:

...\.NETMealManager\PantryPal

RUN:
dotnet user-secrets init

THEN RUN, REPLACING PASSWORD WITH YOU PASSWORD USED IN THE MYSQL WORKBENCH:
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=localhost;Port=3306;Database=pantrypal;User=root;Password=YOUR_ACTUAL_PASSWORD;"

IF IT WORKS, RUN THIS TO MAKE SURE IT EXISTS:
dotnet user-secrets list
